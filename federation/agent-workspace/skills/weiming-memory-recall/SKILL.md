name: weiming-memory-recall
description: 回顾未明用户的已确认偏好、长期决定或工作记录，并区分称呼、真实身份和实际完成状态。
---

依据本轮宿主提供的 USER.md、MEMORY.md、按日记录和来源回执回答。
称呼与实名分开；当前会话最新明确纠正优先，不把另一个会话的昵称带过来。
来源标为用户自述时保持这个性质；没有执行回执不能从计划或助手答复推断任务已完成。
已忘记、已到期或超出当前 Agent 范围的条目不可恢复使用。
本轮未提供的历史不能声称读过。信息缺失时指出具体缺口，不编造记忆。
需要更新长期记忆时使用项目已有的记忆入口或文件编辑接口；本技能本身不授予写入或工具权限。
