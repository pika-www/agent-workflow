# 服务器文件与命令

Agent 使用后端服务当前账号（本次为 `winfield`）的文件权限，可列目录、按文件名查找、分段读取文本及二进制文件，并申请创建、写入、复制、移动、删除文件或执行命令。操作路径是服务器绝对路径；先用 `stat` 查看符号链接的真实路径，再针对真实路径申请更改。

用户不用先提供路径。“服务器上有什么”会先读取常用数据目录，“服务器上有个视频”会先按视频类型检索，再依据实际文件名、修改时间和大小回答。`discover {}` 返回当前账号主目录、`/srv`、`/mnt`、`/media` 的真实目录条目；`list {}` 默认主目录；`find {"kind":"video"}` 支持 video/audio/image/document，也可用 path 和 pattern 限定目录及文件名。默认检索跳过隐藏目录、凭据、依赖和归档，每个根目录最多扫描 20000 项或 3 秒，最多返回 200 个候选；回执包含截断、错误和跳过范围，不能说成查完了整台服务器。

用户要求把已找到的文件发到当前聊天时，`attach {"path":"实际文件路径"}` 将普通文件只读复制为聊天附件，并返回可打开的真实附件链接。源文件不变，不向其他人或平台发送。音视频上限 50MB，文档及图片上限 10MB，禁止导出凭据、符号链接和特殊文件。多个候选无法区分时先展示实际候选再问一个选择问题，不重复要求用户提供路径。此附件输出沿用聊天文件权限；任意源文件更改和终端命令仍需下述逐项确认。

聊天中的“服务器操作”会展示路径、新内容或完整命令。所有文件更改和终端命令都需逐项点击“确认执行”或“拒绝”。模型工具仅能提交申请，不能确认申请。删除包含目录下的内容，执行后无法在界面撤销；重要文件应先复制备份再申请删除。命令可能间接删除或覆盖文件，因此也必须确认。

申请保存在服务器数据目录的 `private/server-operations/`，有效期 30 分钟。重复确认不重复执行。结构化文件操作在确认时复核文件状态，文件已变化则不执行。执行中断后不自动重试；先核对回执与文件，再重新申请。命令默认最长 30 秒，可申请 1 至 60 秒；输出超过 32000 字节时终止，部分更改仍可能已经发生。长期任务应通过服务器已有的任务或服务机制提交，再查询实际状态。

开启条件为 Linux 非 root 账号、`WEIMING_RUNTIME_LOCATION=server` 和 `WEIMING_SERVER_FILES=1`。本次开关放在 `/home/winfield/services/weiming/learning.env`，由 `weiming-api.service` 读取。Mac 后端不提供该工具；自主学习任务没有此工具的执行授权。工具不会自动提权，命令进程设置 `no_new_privs`，不继承模型 API 密钥等私有配置环境变量。

文件内容和命令输出是资料，不能改变权限或代替用户确认。确认入口保留同源校验；API 仍只监听服务器回环地址，经已有 SSH 入口访问。执行结果、申请和聊天数据均写到服务器。源码留在 Mac。

验证使用服务器独立 `api-data` 与 `fixture` 目录，正式房间不加入测试消息。相关回归为 `tests/test_server_files.py`、`tests/test_server_files.mjs`、原生流式事件与工具协议测试。
